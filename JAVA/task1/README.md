# RSA Key Generation Service (Task J1)

Микросервис для генерации пар RSA ключей с использованием Java NIO и пула генераторов.

## Архитектура

Система состоит из сервера и клиента:

- **Сервер** (`KeyServer`): Прослушивает TCP порт, принимает запросы на генерацию ключей, кэширует результаты
- **Клиент** (`KeyClient`): Подключается к серверу, отправляет имя и сохраняет полученные ключи в файлы

### Особенности реализации

- **NIO с Selector**: Сервер использует неблокирующий ввод/вывод для обработки множества одновременных подключений
- **Пул генераторов**: Фиксированное количество нитей для генерации ключей (задается в командной строке)
- **Кэширование**: Повторные запросы с одинаковым именем возвращают ранее сгенерированные ключи
- **Асинхронная обработка**: Генерация ключей не блокирует обработку новых подключений
- **Очереди доставки**: Результаты генерации передаются клиентам через dedicated очередь

## Запуск

### Подготовка ключа издателя

Сначала необходимо создать приватный ключ для подписи сертификатов:

```bash
# Создание приватного ключа RSA 4096
openssl genpkey -algorithm RSA -out issuer_key.pem -pkcs8 -outform PEM

# Или с помощью Java (пример)
keytool -genkeypair -keyalg RSA -keysize 4096 -alias issuer -keystore issuer.jks -storepass password
keytool -export -alias issuer -keystore issuer.jks -file issuer.crt -storepass password
openssl pkcs8 -in issuer_key.pem -topk8 -nocrypt -out issuer_key_pkcs8.pem
```

### Запуск сервера

```bash
# Базовый запуск
./gradlew runServer -Pargs="--port 9000 --threads 4 --issuer 'CN=KeyIssuer,O=NSu' --key /path/to/issuer_key.pem"

# Параметры командной строки сервера:
# --port <port>        TCP порт для прослушивания (обязательно)
# --threads <N>        Количество нитей генераторов (обязательно)
# --issuer <DN>        Distinguished Name издателя сертификатов (обязательно)
# --key <path>         Путь к PEM файлу приватного ключа издателя (обязательно)
# --help               Показать справку
```

### Запуск клиента

```bash
# Базовый запрос ключа
./gradlew runClient -Pargs="--host localhost --port 9000 --name alice"

# С дополнительными опциями
./gradlew runClient -Pargs="--host 192.168.1.100 --port 9000 --name bob --delay 2 --out ./keys"

# Параметры командной строки клиента:
# --host <host>        Хост или IP сервера (обязательно)
# --port <port>        TCP порт сервера (обязательно)
# --name <name>        Имя для генерации ключа (обязательно, ASCII)
# --delay <seconds>    Задержка перед чтением ответа (по умолчанию 0)
# --abort              Завершить после отправки запроса, не ждать ответа
# --out <directory>    Каталог для сохранения файлов (по умолчанию текущий)
# --help               Показать справку
```

После успешного выполнения клиент сохранит:
- `alice.key` - Приватный ключ в формате PEM
- `alice.crt` - X.509 сертификат в формате PEM

## Протокол взаимодействия

1. Клиент подключается к серверу по TCP
2. Клиент отправляет имя в кодировке US-ASCII, завершенное нулевым байтом
3. Сервер генерирует/извлекает из кэша пару RSA 8192-bit + X509 сертификат
4. Сервер отправляет ответ:
   - 4 байта (big-endian): длина приватного ключа PEM
   - данные приватного ключа PEM
   - 4 байта (big-endian): длина сертификата PEM
   - данные сертификата PEM
5. Соединение закрывается

В случае ошибки сервер отправляет длины 0 для обоих компонентов.

## Тестирование

### Базовое тестирование

Проект включает PowerShell скрипты для тестирования:

```powershell
# Базовые сценарии (Windows)
.\scripts\test_basic.ps1 -IssuerKeyPath "C:\path\to\issuer_key.pem"

# Тестирование кэширования
.\scripts\test_cache.ps1 -IssuerKeyPath "C:\path\to\issuer_key.pem"

# Нагрузочное тестирование
.\scripts\test_many.ps1 -IssuerKeyPath "C:\path\to\issuer_key.pem" -Clients 100 -Threads 8
```

### Ручное тестирование

```bash
# Терминал 1: Запуск сервера
./gradlew runServer -Pargs="--port 9000 --threads 2 --issuer CN=TestIssuer --key issuer_key.pem"

# Терминал 2: Запрос ключа
./gradlew runClient -Pargs="--host localhost --port 9000 --name testuser"

# Терминал 3: Повторный запрос (должен вернуть тот же ключ)
./gradlew runClient -Pargs="--host localhost --port 9000 --name testuser"

# Терминал 4: Тестирование задержки
./gradlew runClient -Pargs="--host localhost --port 9000 --name slowclient --delay 3"

# Терминал 5: Тестирование аварийного завершения
./gradlew runClient -Pargs="--host localhost --port 9000 --name abortclient --abort"
```

### Проверка файлов ключей

```bash
# Просмотр содержимого приватного ключа
openssl rsa -in testuser.key -text -noout

# Просмотр сертификата
openssl x509 -in testuser.crt -text -noout

# Проверка соответствия ключа и сертификата
openssl x509 -in testuser.crt -pubkey -noout | openssl rsa -pubin -in testuser.key -pubout -outform pem
```

## Производительность

- **Генерация ключей**: RSA 8192-bit занимает 10-30 секунд на типичном оборудовании
- **Одновременные клиенты**: Сервер поддерживает сотни одновременных подключений благодаря NIO
- **Кэширование**: Повторные запросы обслуживаются мгновенно
- **Масштабирование**: Количество нитей генераторов должно соответствовать количеству CPU ядер

## Безопасность

⚠️ **Важно**: Эта реализация предназначена только для образовательных целей!

- Приватные ключи передаются по незащищенному TCP соединению
- Ключи хранятся в оперативной памяти сервера без шифрования
- Отсутствует аутентификация клиентов
- Не предназначено для production использования
